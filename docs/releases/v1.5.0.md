# DataEyes Code v1.5.0

v1.5.0 是 DeepSeek Harness 集成的第一阶段。它不替换现有可工作的 Agent 会话、审批和桌面工具，而是引入官方 Cordis 插件生命周期作为下一阶段扩展基础。

## 运行时

- 精确锁定 `@deepseek-ai/cordis@4.0.1`、`@deepseek-ai/dsh-scope@0.1.1-rc.2` 与 `@deepseek-ai/dsh-invariants@0.1.1-rc.2`。
- Planner、Tool Registry 与 Session Factory 作为显式 Cordis 服务安装，依赖按顺序激活并支持可逆卸载。
- 每个 Workbench Session 拥有独立生命周期 scope；切换、删除、清空和退出时会取消任务并释放资源。
- 启动失败进入可观察的兼容模式；启动后核心服务失效则 fail closed，不静默绕过 Harness。
- Workbench 暴露只读运行快照，用于设置中心和任务上下文展示插件、服务、版本、scope 与错误状态。

DSH Scope 只负责生命周期、注册与事件路由，不是安全沙箱。文件、终端、电脑控制和审批的最终权威继续位于 Electron 主进程。

## 界面

- 工作台改成克制的苹果/Codex 风格：中性浅色与深色表面、清晰的侧栏层级、轻量欢迎区和聚焦式 Composer。
- 设置中心、Provider Console 与完全访问确认页统一视觉语言，并保留原有功能。
- 新增 Harness 就绪状态、插件数量和权限边界说明。
- 启动动画改成简洁的品牌标记与本地工作区进度，保留跳过、首次展示和减少动画支持。
- 中等窗口默认收起任务检查器，大屏自动展示，减少主任务区域拥挤。

## 验证

- 全量 Node 测试通过。
- Web 与 Electron renderer 生产构建通过。
- macOS Electron 桌面端以默认本地工作区启动并显示 DeepSeek Cordis 就绪状态。
