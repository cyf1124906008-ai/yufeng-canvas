# YUFENG Agent 1.3.0

v1.3.0 把 Workbench 从“提交后等待结果”升级为可在执行过程中持续协作的桌面 Agent Harness。本阶段的重点是任务干预、安全授权、推理控制、设置中心和自动化，而不是增加新的画布节点。

## 运行中协作

- 任务执行时输入框保持可用，可发送新的执行引导。
- Planner 正在响应时，新引导会废弃旧响应并重新规划。
- 工具正在执行时，引导会排队到安全检查点，不会强行并发修改状态。
- 等待审批时发送引导，会放弃旧动作并重新规划，旧的工具参数不会被重放。
- 停止后只有底层操作真实结束才会开放“继续”，避免旧工具与续跑任务同时执行。
- 失败或取消的任务可在同一会话中继续，并保留可审查的事件记录。

## 权限与安全

- 审批模式扩展为只读、每次审批、自动执行和完全访问。
- 工具能力按文件、终端、电脑控制、创作模型与 MCP 分组，可多选启停。
- 完全访问必须经过独立风险说明页、确认勾选和 Electron 原生确认。
- 授权绑定当前窗口和工作区身份，不返回可复用 token，不持久化，并在切换工作区、刷新、崩溃或退出时撤销。
- 完全访问不会绕过工作区边界、realpath / symlink 检查、文件 SHA 校验、参数校验或操作系统权限。
- 自动化任务禁止使用完全访问，恢复的历史会话统一回到“每次审批”。

## 推理强度

- 支持自动、极速、轻量、标准、深度、极致和 Max 七档。
- 选项通过真实 Provider 请求参数进入 Planner 调用。
- Provider 明确返回不支持该参数时只重试一次模型默认强度，并按 Provider、Endpoint、Model 缓存兼容性；鉴权、限流和无关校验错误不会被误判为兼容问题。
- Max 运行状态只展示计划、工具和 observation 推导出的公开阶段，不展示或伪造隐藏思维链。

## 设置与自动化

- 新设置中心包含常规、外观、Agent、工具与权限、API 与模型、自动化、数据和关于八个分类。
- 支持主题、密度、Inspector、后台运行、登录启动、防休眠、行动上限、审批模式、推理强度和工具组偏好。
- 自动化计划持久化到本机，通过真实 Workbench 执行，支持排队、等待审批、成功、失败和取消状态。
- App 异常退出后的未完成自动化会标记失败，不会静默重放。

## 界面与桌面体验

- Composer 新增“引导”“停止”“继续”和“正在安全停止”状态。
- 推理强度提供紧凑选择器，Max 使用独立视觉层级。
- 设置中心和 Composer 完成窄窗口适配。
- Electron 支持后台运行、登录启动和任务运行期间防止系统休眠。
