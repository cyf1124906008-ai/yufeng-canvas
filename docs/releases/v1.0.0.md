# YUFENG Canvas v1.0.0

YUFENG Canvas 从 `0.1.x` 试验版本进入 `1.0.0` 正式版。本版本重点不是单点功能，而是把云端模型、ComfyUI 风格专业工作流、Drama 短剧生产和本地资产保存整合进同一个 AI 创作工作区。

## 下载

- Windows 安装包：`YUFENG-Canvas-Setup-1.0.0.exe`
- 自动更新文件：`latest.yml`、`.blockmap`
- 稳定下载名：`YUFENG-Canvas-Latest.exe`

> 升级前建议先在应用设置页导出本地数据，并单独备份本地素材目录。v1.0.0 已禁用静默更新，下载和安装新版前都会提示备份。

## 主要变化

### 1. 云端模型优先

- 通过 API Key + Base URL 接入图片、视频和文本模型。
- 支持完整 endpoint 输入时自动反推 Base URL，例如 `/v1/images/generations`、`/v1/chat/completions`。
- 模型同步会尝试 `/v1/models`、`/models`、`/api/v1/models`。
- 常见 HTTP 错误改成更适合普通用户理解的中文提示。

### 2. ComfyUI 风格专业工作流

- 不要求用户本地部署模型，但吸收 ComfyUI 的专业工作流参数和画布思路。
- 工作流节点支持 Prompt、Negative Prompt、Seed、Steps、CFG、Sampler、Scheduler、参考图、重绘、放大等中文化配置。
- 新增复杂工作流模板，重点覆盖角色一致性、产品广告、局部修复、图生视频、短剧分镜等生产场景。

### 3. Drama 短剧工作区

- 新增短剧项目结构和 Drama pipeline。
- 支持故事、角色、场景、镜头、首帧、视频任务进入同一个项目画布。
- 目标是让用户用自然语言驱动画布，而不是只和 AI 聊天。

### 4. 后台任务和资产持久化

- 图片生成迁移到 Electron 主进程执行，前端等待超时后主进程继续等待供应商结果。
- 刷新页面后可以恢复仍在运行的图片任务。
- 视频、Comfy、拆图结果尽量保存为本地项目资产，减少刷新后图片丢失。
- 九宫格拆图支持 2x2、3x3、4x4、横三格、竖三格，并写入资产目录。

### 5. 更新和备份

- 版本号升级到 `1.0.0`。
- 关闭静默下载和静默安装。
- 检测到新版本、准备安装前均提示用户备份。
- 设置页增加更清晰的数据导出和本地素材目录入口。

## 验证

本版本发布前已通过：

```bash
pnpm build
pnpm desktop:renderer
```

## 注意事项

- YUFENG Canvas 不内置用户 API Key。
- 模型权重不打包进安装包。
- 不同供应商对图片、视频、参考图、尺寸、采样器等参数支持不同；不支持的参数会尽量自动回退或给出中文错误。
- 如果生成任务在供应商侧已扣费但前端等待超时，请不要立即重复提交；应用会尽量在后台等待并恢复结果。
