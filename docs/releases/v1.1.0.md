# YUFENG Agent 1.1.0

YUFENG 从 Creative Agent 首页升级为通用桌面 Agent Workbench。

## 新功能

- Codex 风格三栏工作台：任务历史、消息与工具轨迹、运行检查器。
- 通用多轮 `WorkbenchSession`，支持 `message`、`tool_call`、`finish` 和 observation 循环。
- 本地工作区工具：列目录、读文件、搜索与写入。
- 受控终端：无 shell 拼接、有限输出、超时、轮询和停止。
- macOS 电脑工具：权限检查、屏幕分析、打开应用、坐标点击和文本输入。
- Creative Agent 作为图片 / 视频工具继续保留。
- 本地任务事件历史与中断恢复识别。

## 安全说明

写文件、运行命令、屏幕捕获、打开应用、点击、输入文本和 Creative 模型调用都要求逐项批准。终端不是操作系统沙箱：批准后的程序拥有当前用户权限，执行前请检查命令和参数。

本地构建的 macOS App 未做 Apple Developer ID 公证，首次打开可能需要在 Finder 中右键选择“打开”。
