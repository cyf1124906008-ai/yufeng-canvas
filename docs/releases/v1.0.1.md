# YUFENG Canvas v1.0.1

这是一个针对 v1.0.0 的可见产品方向修正版本。

## 关键修正

- 首页、画布控制台、右侧工作区不再把“本地 ComfyUI / 内置 ComfyUI”作为普通用户主入口。
- 主入口统一改成“云端专业工作流 + 短剧工作区”。
- 本地 ComfyUI 只保留在“高级：本地 Comfy”设置页，作为已经会用本地环境的专业用户可选能力。
- 应用启动时不再自动装载本地 ComfyUI。
- 安装包不再打包 `.reference-repos/ComfyUI` 和 `.reference-repos/huobao-drama` 源码资源，避免用户误解为必须部署本地模型。

## 验证

```bash
pnpm build
pnpm desktop:renderer
```

## 升级说明

直接覆盖安装即可。升级前仍建议在设置页导出本地数据，并单独备份素材目录。
