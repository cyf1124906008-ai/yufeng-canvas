# YUFENG Agent 1.2.0

v1.2.0 把通用桌面 Workbench 升级为更可审查的 Agent Command Center。本版本重点不是增加更多高权限工具，而是补齐计划、文件 diff、条件回滚、终端实时状态和 Provider 配置体验。

## 新功能

### Agent Command Center

- 新三栏任务工作台：工作区与历史、消息和实时工具轨迹、计划 / 文件变更 / 作品检查器。
- 支持结构化任务计划，步骤状态为 `pending`、`in_progress`、`completed`。
- 工具进度、计划和文件变更均来自 append-only 事件，可从本地历史重建。
- Provider Console 集中管理连接、能力专用 Key / Base URL、连接测试、模型同步、DataEyes 实测目录和手动模型。

### 结构化文件修改

- `workspace.read` 返回文件 SHA-256。
- 新增 SHA 绑定的行级 `workspace.patch`，精确校验旧行、文件基线和最终换行。
- 补丁成功后生成结构化 `workspace_diff`，包含 before / after SHA 与完整 hunks。
- 写入使用同目录临时文件和 rename；路径逃逸、符号链接、非 UTF-8、敏感路径和冲突都会拒绝。

### 条件回滚

- 每个结构化 diff 在当前 App 会话内生成一次性 rollback record。
- 回滚前必须确认记录仍存在且当前文件 SHA 等于原 diff 的 after SHA。
- 逆向结果必须精确恢复原 before SHA，否则不会写入。
- 回滚同样需要 Workbench 批准和 Electron 完整原生确认。

回滚不是永久撤销。切换工作区、记录被淘汰或 App 重启后，历史里的旧 token 不能再执行；UI 应显示“条件回滚”，不能显示为无条件可用。

### 终端可观察性

- `terminal.run` 增加 `starting`、`started`、运行中和最终阶段事件。
- 运行中事件只记录输出长度、字节上限、截断、超时和 exitCode 等元数据；不会持久化 stdout / stderr 分片，避免凭据跨分片时绕过脱敏。
- 命令结束后，完整的有界 stdout / stderr 作为一次 observation 统一脱敏并展示。
- `termination_unconfirmed` 继续作为明确失败边界，不会伪装成全部后代进程已经停止。

## 安全与隐私

- `workspace.patch` 与 `workspace.revert_patch` 都是危险工具，必须逐项批准并接受 Electron 原生确认。
- 原始 rollback hunks 只保存在 Electron 当前进程内；持久事件只保存脱敏 diff 和 opaque token。
- 恢复的脱敏任务历史不能重放文件修改、终端命令或电脑操作。
- API Key、Authorization、Cookie、私钥、截图 base64 和裸媒体字节不会写入 Workbench 历史。

## 当前限制

本版本明确没有实现：

- 真正 PTY 或交互式 shell；当前终端仍是 `shell:false` 的非交互式受控子进程。
- 任务级多并发隔离、自动 Git worktree 或容器沙箱；任务操作同一个用户选择的 workspace root。
- `read-only` / `ask` / `full-access` 等可配置权限模式或持久命令 allowlist。
- 中断任务的 checkpoint 续跑。

## 升级说明

- 版本号升级到 `1.2.0`。
- 现有 Provider 和本地任务历史格式保持兼容；新增事件会被旧历史投影安全忽略。
- 旧任务中的 diff 不具备当前进程的 rollback record，因此不能从历史中直接回滚。
- 升级前仍建议导出本机配置，并备份需要保留的项目与素材目录。
