# DataEyes Code v1.4.0

## 这次更新

- 默认工作台完成 DataEyes Code 品牌与 Optical Runtime 视觉重构，采用三栏桌面布局、启动过渡、浅色 / 深色主题和减少动效支持。
- 新增本地生成的 Optical Runtime 视觉资产、DataEyes 光学标记和统一的工作台组件层级。
- 设置中心改为 Control Plane 风格，覆盖外观、Agent、工具与权限、API / 模型、自动化、数据和关于。
- API / 模型页改为 Provider、连接、模型目录和运行状态的控制面板，保留同步、导入、连接测试和模型切换。
- 模型选择只展示当前 Provider 真实可用的目录，不再伪造默认模型；空目录会给出配置引导。
- 保留 Electron `appId`、旧用户数据目录、MCP 名称和存储键，确保旧安装可原位升级。
- macOS / Windows 安装包统一使用 `DataEyes Code` 品牌名称。
