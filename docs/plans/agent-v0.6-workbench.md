# Agent V0.6：Desktop Workbench

## 产品定位

V0.6 把 YUFENG 从“自动完成图片 / 视频的 Creative Agent”升级为通用桌面 Agent Harness。

用户提交的是任务，不是工作流。Agent 可以逐步规划、调用工具、观察结果、请求批准并继续执行；图片和视频生成降为工具能力之一。

## 工作台界面

- 左栏：新任务、本地任务历史、工作区选择。
- 中栏：用户与 Agent 消息、计划进度、工具调用、审批请求、错误与最终答复。
- 底部：固定任务输入框、模型入口、执行模式和停止按钮。
- 右栏：当前计划、工作区、文件活动、工具状态、作品与运行统计。
- 不再提供 Canvas 节点、连线或工作流编辑入口。

## 通用 Agent 协议

Agent 每次只返回一个 next action：

```text
message    → 向用户说明或追问，结束当前 turn
tool_call  → 调用一个已注册工具，观察结果后继续
finish     → 结束当前 task，并给出最终答复
```

工具统一声明名称、描述、输入 schema、风险等级和审批策略。工具执行结果作为 observation 回到 Agent；失败默认也是可观察结果，不直接终止整个 task。

## 本地工具边界

V0.6 首批工具：

- 工作区：选择根目录、列目录、读文本、搜索文本。
- 终端：以 executable + args 形式启动受控进程，支持轮询、超时、输出上限和取消。
- macOS：权限状态、屏幕截图、打开 App、坐标点击、输入文本。
- Creative：复用现有图片 / 视频 Agent 作为一个工具，而不是整个产品入口。

文件工具只允许访问当前 workspace root。桌面 App 首次启动自动绑定专用默认目录，用户也可以切换到项目目录；路径需要经过 realpath、符号链接和范围校验；`.env`、私钥和 credentials 等敏感文件默认拒绝自动读取。终端不使用 shell 字符串拼接。所有终端和电脑副作用都必须先进入 `awaiting_approval`，用户明确允许后，再由 Electron 主进程用包含规范化参数的原生对话框确认一次才能执行。

## 隐私与可观察性

- Agent 事件流只保存可序列化、已脱敏的消息、工具参数摘要和 observation。
- API Key、Authorization、Cookie、裸媒体字节和屏幕截图 base64 不进入任务快照。
- UI 只展示规划摘要和工具事实，不展示模型的隐藏思维链。
- 浏览器预览可展示工具不可用状态；真实电脑工具只在 Electron App 中启用。

## V0.6 验收标准

- 主界面已经是任务工作台，不是生图落地页。
- 同一 session 支持多轮用户消息。
- Agent 能选择并调用通用工具，工具结果会回到下一次决策。
- 危险工具在批准前绝不执行，拒绝后 Agent 可以解释或改道。
- Electron 中默认绑定专用工作区，也可切换工作区，并真实完成安全读取、终端命令和至少一项 macOS 控制。
- Creative Agent 现有能力与测试保持可用。
